# Aim-3 functional demo — diet ↔ gut-microbial function

Demonstrates the functional layer end-to-end: a HUMAnN 3 table → mechanism-focused **axis features**
(estrobolome / glycogen-starch / SCFA) → the repeated-measures **MaAsLin bridge**. This is Aim 3 of the
gut–vagina-axis proposal running with the exact same association engine as Aims 1–2, just on a functional
feature table instead of a species table.

## Two inputs here

1. **`data/demo_genefamilies_excerpt.tsv`** — a trimmed, *real* HUMAnN 3 gene-family table (biobakery's
   demo output, `demo_genefamilies_with_names.tsv`, MIT-licensed; kept small for an offline test). Used
   to prove the parser + dictionary work on genuine HUMAnN output.
2. **`data/ecs_merged.tsv`** (generated by `make_demo.py`) — a synthetic EC-level merged table across a
   repeated-measures cohort (48 participants × rectal/vaginal × 2 timepoints) with planted diet→function
   signals, used for the end-to-end run.

## Run it

```bash
python example/functional_demo/make_demo.py      # writes data/ecs_merged.tsv + data/metadata.tsv

# Step 1 — extract axis features from the HUMAnN table
python -m vmbdiet.cli functional \
    --humann example/functional_demo/data/ecs_merged.tsv \
    --out    example/functional_demo/results --aggregate sum

# Step 2 — associate them with diet (random intercept per participant)
python -m vmbdiet.cli maaslin \
    --features example/functional_demo/results/axis_feature_table.tsv \
    --meta     example/functional_demo/data/metadata.tsv \
    --predictors fiber,animal_protein --covariates age \
    --group participant --body-site body_site \
    --normalize none --models abundance \
    --out example/functional_demo/results/maaslin
```

## What it recovers

Step 1 matches the dictionary against the table (auto-detects EC level) and sums each mechanism:

| category | matched (EC) |
|---|---|
| estrobolome | `3.2.1.31` β-glucuronidase |
| glycogen_starch | `3.2.1.1` α-amylase, `3.2.1.3` glucan-1,4-α-glucosidase |
| scfa | `2.7.2.7` butyrate kinase, `2.7.2.1` acetate kinase, `2.8.3.8` acetate CoA-transferase |

Step 2 recovers exactly the planted biology, all q<0.001, with the non-planted links correctly null:

| feature | predictor | effect | q |
|---|---|---|---|
| glycogen_starch | fiber | +0.34 | <0.001 |
| scfa | fiber | +0.18 | <0.001 |
| estrobolome | animal_protein | +0.15 | <0.001 |
| estrobolome | fiber | +0.01 | 0.60 (null ✓) |

## Two things this demo is careful about

- **Normalization.** `maaslin` TSS-normalizes by default (correct for a full compositional profile). A
  3-column *axis-score* table is **not** a closed composition, so it is run with `--normalize none`
  (absolute capacity, log-transformed) — otherwise one mechanism rising mechanically pushes the others
  negative. For a full per-feature functional profile, keep the default TSS and subset the results.
- **Estrobolome caveat.** EC `3.2.1.31` / KO `K01195` capture *total* bacterial β-glucuronidase; they do
  not isolate the estrogen-reactivating GUS loop-classes (Ervin 2019). The feature means "total GUS
  capacity" — see [docs/functional-aim3.md](../../docs/functional-aim3.md).

## On real data

`make_demo.py` is synthetic. For a public prototype, `vmbdiet.write_cmd_export_R()` emits an R snippet
that pulls a **curatedMetagenomicData** study's pre-computed HUMAnN 3 pathway/gene table + metadata to
TSV (no read-level compute), which `vmbdiet functional` then consumes — the same path FRESH's HUMAnN 3
output will take.
